# Marketing & Product Performance Dashboard

A two-page Power BI report built on a practice dataset (generated data, not company data) to learn dashboard design and DAX.

## Page 1: Campaign performance

- Summary cards for revenue, net profit, ROI and units sold.
- Budget against net profit for the top 10 campaigns.
- A keyword slicer (affordable, durable, innovative, stylish).

## Page 2: Product and customer insights

- Product table with units sold, revenue and average customer satisfaction (CSAT, scored 1 to 4).
- Cards for conversions, average order value and average CSAT.
- Revenue by subscription tier.
